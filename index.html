About CodeChecker

CodeChecker is a small Android app for people who write code on their phone. Paste Java, JavaScript or a Sketchware custom code block, tap Check Code, and you get a green “Code is valid” or the exact error with its line number.

The editor has line numbers, syntax colours and a highlighted error line, in a calm off-white and violet theme.

Sketchware mode wraps your snippet so a real Java compiler can read it. Things that only exist inside Sketchware, like component names and Android classes, can’t be validated. They are listed as not verified instead of being reported as errors.
